## 内容说明

这五篇文档从不同角度完整覆盖了以太网交换机芯片的知识体系：

- **第0篇（入口）**: 完全零基础入门指南，15步渐进式学习 + 大白话术语对照
- **第一篇**: TCP/IP协议基础 + 5级包处理流水线逐级拆解 + 专业术语速查
- **第二篇**: 从SerDes模拟前端到数字流水线到CPU子系统的完整芯片架构
- **第三篇**: 叙事式手把手跟踪一个包从电信号进来到出去的完整旅程
- **第四篇（补充）**: 数据中心技术(VXLAN/RoCEv2/PFC/ECN) + 芯片工程实战(DFT/Bring-up/调试) + 性能指标 + 补充协议 + 面试题
